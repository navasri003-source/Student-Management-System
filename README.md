# Student Management System

## About
A simple Student Management System developed using C++.

## Features
- Add student details
- View all students
- Search students by ID
- Delete student details
- Check student marks

## Technologies Used
- C++
- Structures
- Arrays
- Functions
- Loops

## How to Run
1. Copy the code from `main.cpp`.
2. Open any online C++ compiler.
3. Paste the code and click Run.

## Note
Student details are saved in a file named `students.txt` when the program runs in a folder that supports file storage.
